WHAT THAT USED TRACTOR IS ACTUALLY WORTH

Interactive

Class, age, hours and condition — get the price range a used machine is actually worth before you negotiate.

Below the calculator we show the depreciation curve it uses and why the hour meter moves the number more than the model year does.

How the estimate works

Three inputs drive the range. Age applies a depreciation curve that is steep in the first year and flattens after — the same shape as vehicles, and the reason a one-to-three year old machine is usually the best value on the lot. Hours against age adjusts for how hard the machine worked: under about 100 hours a year is light private use, and the same total compressed into two years means something different. Condition applies a multiplier you set yourself, because no calculator can see rust.

Two honest limits. The depreciation curve is modelled rather than surveyed from transaction data, so the output is a negotiating anchor and not an appraisal. And the reference new prices behind it are manufacturer MSRP — real transaction prices sat above that when the machine was new, which makes the model conservative rather than optimistic.

FAQ

Questions & Answers

Answered from the same sources as the tables above — each figure is linked on the page it comes from.

Do hours matter more than age?

Both, but a low-hour older machine usually beats a high-hour newer one on a private lot.

What does dealer-serviced actually buy me?

Documented maintenance, and a much shorter list of surprises in the first season. It is not a warranty, but it is evidence — and the absence of any record on a dealer machine is a question worth asking out loud.
